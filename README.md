• Project documentation.

This web application was built by adding features on the already existing application designed in [Task 6](https://github.com/persianflower/LNT_Task_6): 
[Application](https://task6lnt.streamlit.app/). Here, instead of only allowing a user to use the model to predict the output, we also allow them to visualize the confidence level
of their prediction. This allows them to better understand the accuracy of our model. An additional page to view the trained model metrics was also added to see the model performance
during training. To conclude, this webpage introduces additional features which allows the user to get full experience of our Prediction website.
